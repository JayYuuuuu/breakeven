## 技术实现

### CSS样式
- Tab按钮采用紧凑设计，适合在标题栏中显示
- 使用flexbox布局，支持响应式设计
- Active状态使用主题色高亮显示

### JavaScript功能
- `initTabs()` 函数初始化tab切换
- `updateTabTitle()` 函数动态更新右侧标题
- `updateDecisionDisplay()` 函数更新投放决策显示
- `updateAnalysisDisplay()` 函数更新利润推演显示
- 所有输入框都触发相应的计算和显示更新

### HTML结构
- 左侧参数输入区域完全独立
- 右侧每个tab都有独立的content区域
- 右侧标题使用`<span id="tabTitle">`包装，支持动态更新
- 使用CSS的display属性控制显示/隐藏

# 页面功能特性说明

## Metro页面 (metro.html) - 费用可视化墙

### 🆕 新增功能：智能数据合并

Metro页面现在支持自动合并示例数据和用户本地数据，提供更灵活的商品选择体验。

#### ✨ 主要特性

1. **智能数据合并**
   - 自动从localStorage加载用户数据
   - 与示例数据进行智能合并
   - 以用户数据为准，自动替换重复项

2. **去重逻辑**
   - 基于货号(SKU) + 平台(Platform)组合进行去重
   - 支持同一货号在不同平台存在不同数据
   - 避免数据冲突，确保数据一致性

3. **手动刷新**
   - 提供🔄刷新按钮
   - 可在商品分析页面添加新商品后手动刷新
   - 实时获取最新数据

#### 🔄 数据流程

```
商品分析页面 → 添加/修改商品 → 自动保存到localStorage
                                    ↓
Metro页面 ← 自动合并示例数据 + localStorage数据 ← 手动刷新
```

#### 📱 使用方法

1. **自动合并**：页面加载时自动完成数据合并
2. **手动刷新**：点击搜索框旁的🔄按钮
3. **实时同步**：在商品分析页面操作后，返回metro页面刷新即可

#### 💡 使用场景

- **数据更新**：在商品分析页面修改商品参数后，metro页面可立即获取最新数据
- **新商品添加**：添加新商品后，无需重启页面即可在metro页面使用
- **数据同步**：确保多个页面间的数据一致性

#### 🔧 技术实现

- 使用`mergeProductData()`函数进行数据合并
- 基于`product_analysis_data`键从localStorage读取数据
- 智能去重算法，确保数据完整性
- 错误处理机制，保证系统稳定性
