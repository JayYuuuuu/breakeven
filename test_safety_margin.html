🔍 安全边际分析测试

验证修复后的 safetyMarginAnalysis 函数是否正确返回两种口径的边际

测试用例 1：标准情况

保本广告费 A = 8.29 元/单
当前 CVR = 15%
当前 CPC = 1.18 元/点击
实际 CPA = CPC/CVR = 1.18/0.15 = 7.87 元/单

测试用例 2：危险情况

保本广告费 A = 8.29 元/单
当前 CVR = 10%
当前 CPC = 1.50 元/点击
实际 CPA = CPC/CVR = 1.50/0.10 = 15.00 元/单

测试用例 3：边界情况

保本广告费 A = 8.29 元/单
当前 CVR = 20%
当前 CPC = 1.658 元/点击
实际 CPA = CPC/CVR = 1.658/0.20 = 8.29 元/单（刚好保本）

数学关系验证

理论关系：ΔCPC = CVR × ΔCPA
验证：MaxCPC - CPC = CVR × (BE-CPA - CPA)
