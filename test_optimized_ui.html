🔄 两个模块的互补关系

投放决策条（点击端）:

  • 显示单位：元/点击
  • 用途：判断能否继续提高CPC
  • 计算：MaxCPC - 实际CPC
  • 示例：+0.06元/点击 = 可以再提高0.06元CPC

即时诊断（订单端）:

  • 显示单位：元/单
  • 用途：判断每单广告费离临界有多远
  • 计算：保本广告费 - 当前CPA
  • 示例：+0.42元/单 = 每单还有0.42元广告费空间

数学关系: 点击端边际 = CVR × 订单端边际

0.06 = 0.15 × 0.42 ✓
